07 / METHODOLOGY
Network extraction: Electricity infrastructure is retrieved from OpenStreetMap using Overpass API queries or loaded from a user-supplied GeoJSON FeatureCollection.

Line length: Calculated from the geographic coordinates using the Haversine distance formula. This is an approximate geodesic measurement, not an engineering survey.

Voltage classification: Transmission is classified at 66 kV and above. Distribution is below 66 kV. Missing or unreadable voltage is classified as unknown.

Limitations: OpenStreetMap coverage may be incomplete. Unmapped infrastructure is not represented. No claim of official national grid completeness is made.
