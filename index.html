Methodology

Administrative units: Census enumeration area polygons from the supplied GitHub GeoJSON.

Rainfall dataset: UCSB CHIRPS daily precipitation, ClimateSERV datatype 0.

Spatial statistic: Daily area-average rainfall for the selected polygon geometry.

Accumulation: Sum of daily area-average rainfall values for the selected period.

Units: Millimetres (mm).

Important: CHIRPS is a rainfall estimation product, not a direct rain-gauge observation at every location. Historical rainfall analysis is not a future forecast.
